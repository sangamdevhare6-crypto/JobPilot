# JobPilot AI — Job Application Tracker

A polished frontend prototype for an AI-powered job application tracker.

## GCP-ready architecture
- Firebase Hosting — frontend hosting
- Firebase Authentication — identity
- Cloud Run — backend/API services
- Firestore — application data
- Cloud Storage — resumes/documents
- Vertex AI — resume analysis, job matching and recommendations
- Cloud Functions — event-driven automation
- Cloud Scheduler + Pub/Sub — reminders and async workflows
- BigQuery — analytics
- Cloud Logging + Monitoring — observability
- IAM + Secret Manager — security

This ZIP contains the frontend prototype only. The UI uses no external application backend.
